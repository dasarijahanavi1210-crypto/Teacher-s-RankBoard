# Teacher's RankBoard

For teachers to manage class marks, see average, and find the Rank 1 student.
Made with Python.

## Features
- Add many students
- Add marks for 5 subjects: Maths, Physics, Python, Chemistry, English
- Show all students marks
- Show average of each student
- Find Rank 1 Student
- Change marks if teacher entered wrong
- Add new student anytime

## How To Run
1. Run `main.py`
2. Enter how many student marks you want to enter
3. Enter student name and marks
4. Choose option from menu:
   - 1 = Show all students
   - 2 = Add new student
   - 3 = Change marks
   - 4 = Show Average
   - 5 = Show Rank 1 Student
   - 6 = Exit
